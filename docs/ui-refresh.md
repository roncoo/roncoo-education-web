# 学员门户 UI 改版

本轮仅改动学员门户，保留 Nuxt、Vue、Element Plus、现有路由和业务接口。主色为 #2563EB，桌面内容区最大宽度为 1200px，平板课程列表为两列。首页轮播、分类、专区、品牌、导航和页脚继续由后台配置。

## 组件职责

- Common/Header、Footer 和布局：站点框架与导航；useWebsite 共享站点配置。
- Course/Card、Filters、Chapter：课程展示、URL 分类状态和目录导航；收藏使用独立按钮。
- Account/LearningCard、AccessForm、AuthShell：学习进度、账号表单及统一认证布局。useAccessForm 管理校验、验证码倒计时与原认证 API。
- Common/State、Image：加载、空内容、错误重试、图片失败占位。
- Common/Pay：下单、扫码、支付结果和刷新事件；支付编码遵循后端 11/21/100，关闭或卸载清理轮询。
- Study/Catalog 与 useStudyPlayer：目录展示和播放器生命周期、签名、课时切换、进度上报、错误恢复。
- useCatalog：课程与讲师列表的 URL 查询及分页；忽略已过期请求的响应。

## 本地验收

1. 在项目目录运行 pnpm dev，保持本地网关 localhost:7700 可访问。
2. 使用已安装的 Playwright 包和 Chrome，运行 node tests/ui-smoke.cjs；外部 Playwright 安装可通过 PLAYWRIGHT_MODULE 指定模块路径，UI_BASE_URL 可覆盖站点地址。
3. 浏览器脚本拦截业务请求，以测试数据验证购买、订单和学习状态，不会向真实系统提交订单、评论或学习进度。
4. 截图和结果写入 .data/ui-review/，该目录已加入忽略规则。

已验证 1920、1440、1280、1024px 下课程网格、详情、认证表单、收银台和学习页无横向溢出；覆盖分类、分页、前进后退、搜索类型刷新、收藏不跳转、错误重试、空列表、个人中心、支付成功/失败/关闭、下一节/最后一节、无权限与进度失败、表单错误聚焦及 404。另用本地后端真实数据检查首页、详情和登录页面，并查看截图。

## 联调边界

自动化浏览器采用 Chrome，平板以视口尺寸模拟。支付、授权、短信和播放器事件使用模拟响应，不代表已通过真实支付渠道、微信扫码授权、短信送达或第三方视频播放联调；上线前需在测试环境验证这些外部能力。后台管理的课程介绍、讲师介绍、版权及协议富文本沿用现有信任边界，ESLint 会保留这些 v-html 提示。

## 第二轮视觉精修

延续蓝色品牌，加入深蓝色学习入口、品牌展示区与页脚，建立清晰的视觉重点。首页按欢迎区、运营轮播、兴趣分类、课程专区排列；分类使用浅色图标块，专区使用序号和中文辅助标题。课程卡片统一封面比例、课程类型、两行标题及价格分隔区，悬停和键盘聚焦均显示封面入口。学习中心调整侧栏、状态标签、进度和按钮间距；认证页使用深蓝品牌区与白色表单双栏。新增 Common/Icon 统一线性 SVG 图标，仅承担装饰展示，不改变按钮和链接的可访问名称。真实页面截图保存在 .data/ui-design-v2/。
